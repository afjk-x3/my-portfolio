# Strike sound credits

All four clips are derived from **"20 Sword Sound Effects (Attacks and Clashes)" by StarNinjas**, released under **CC0 1.0 (public domain)**:
https://opengameart.org/content/20-sword-sound-effects-attacks-and-clashes

Source archives: `sword_-_starninjas.zip` (sword attacks) and `sword_clash_-_starninjas.zip` (sword clashes), downloaded 2026-09-17.

Each clip was decoded, mixed, trimmed, normalised to a 0.9 peak, given a 5 ms fade-in and a 50 ms fade-out, and exported as 22,050 Hz mono 16-bit WAV.

| File | Built from | Edit |
| --- | --- | --- |
| `slash.wav` | `sword.7.ogg` | From 0.18 s, 0.36 s long |
| `stab.wav` | `sword_clash.2.ogg` | From 0.02 s, 0.42 s long. Also played at 1.8× speed as the PERFECT ring. |
| `miss.wav` | `sword_clash.4.ogg` | From 0.03 s, slowed to 0.45× and low-passed at 900 Hz for a dull thud, 0.45 s long |
| `finisher.wav` | `sword.2.ogg` + `sword.3.ogg` + `sword_clash.3.ogg` | Two slashes timed to the X (0 s, 0.16 s) and a clash at 0.42 s under "ANYO COMPLETE", 1.15 s long |

CC0 requires no attribution; this file records the source anyway.
